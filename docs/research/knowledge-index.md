## Promotion Rules

- Link the report, evidence commit, review date, confidence, and affected paths or symbols.
- Require `evidence_dirty: false` and verify the report's source manifest hash before promotion.
- Promote only claims verified against live repository code or primary external sources.
- For improvements, include the report, evidence commit and manifest hash, review date, affected paths or symbols, priority, dependencies, verification command, and implementation status.
- Mark replaced claims `superseded`; preserve the original report for auditability.
- Keep dependency audits separate; they already run through CI and are not the purpose of this hub.
